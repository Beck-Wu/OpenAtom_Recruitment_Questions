# 1. 在 Transformer 出现之前，RNN、LSTM 等序列模型主要存在哪些局限？
- 1. RNN和LSTM都要按照时间顺序进行，因此处理数据低效
- 2. 信息在长距离传播下会有极大损失
- 3. 无论输入序列有多长、信息有多丰富，都必须被塞进同一个固定维度的向量里，这造成了严重的信息丢失。
# 2. Transformer 与 RNN 在处理序列时，最大的结构区别是什么？
- Transformer核心是自注意力机制，能全局关联数据；RNN核心是循环结构，处理数据时按时间顺序进行
# 3. Transformer 中最核心的公式之一是：
$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
## a.Q、K、V 分别起什么作用？
- Q用于查找其他数据；K用于被查找；V是内容本身，当Q和K匹配后，模型会抽取对应的V向量
## b.QK^T 得到的结果表示什么？
- 表示token间的相关性
## c.softmax 在这里做了什么？
- 归一化，将QK^T的值变为0到1之间的值，使其概率化，方便与V相乘
## d.为什么还要除以 \sqrt{d_k}？如果不缩放，可能带来什么问题？
- 防止点积的值随着维度增大而变得非常大，这样会在softmax计算后接近0，导致梯度消失
# 4. 为什么要使用多个 Attention Head？
- 不同的head会关注不同的特征，提高模型的丰富度
# 5. 为什么 Transformer 需要 Positional Encoding？为什么作者使用sin和cos函数来表示位置信息？
- 人类语言的词语在句子中的顺序很重要，位置编码能更好模拟人类语言
- 三角函数有和差化积格式，sin(a+b)=sinacosb+cosa+sinb,所以pos+k的信息可以由pos线性变换，因此当模型想要知道两个词之间的相对距离时，可以通过线性变换轻而易举地算出来。
- 三角函数具有无限延展性，可以外推到训练时未见过的超长序列
# 6. 为什么 Decoder 中需要使用 Masked Self-Attention？
- 如果不使用，模型在未生成完句子时就已经看到所有词，这相当于作弊，不利于训练出由前文推断下文的能力
# 7. Decoder 和 Encoder 相比，多了什么 Attention 结构？
- Cross-Attention即交叉注意力机制
# 8. Residual Connection 和 Layer Normalization 在 Transformer 中分别起什么作用？
- Residual Connection：缓解梯度消失，让深层网络能训练；保留原始信息；让训练更稳
- Layer Normalization：稳定训练；不依赖 batch；加速收敛
