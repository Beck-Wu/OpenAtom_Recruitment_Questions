# 1. 卷积层是什么？在 CNN 中有什么作用？
- 卷积层是用小窗口在图片上滑动，提取特征。
- 在CNN中能提取特征，减少运算量。
# 2. 卷积层与全连接层相比，在处理图像时有哪些优势？
- 1，能提取特征
- 2，保留特征的位置信息
- 3，减少运算量
- 4，平移不变，特征在图片任何地方都能识别
# 3. 卷积核越大，模型一定越好吗？为什么很多 CNN 更喜欢连续使用多个较小的卷积核，而不是直接使用一个很大的卷积核？
- 不一定越好
- 用很大的卷积核会增加参数的数量，增加运算量
- 用多个小卷积核，便会多次使用激活函数，增加了模型的拟合能力
- 用多个小卷积核能减少过拟合现象的发生
# 4. Pooling 有什么作用？Max Pooling 和 Average Pooling 分别做了什么？
- 池化能降低数据量，从而降低计算量；并且能强化特征，弱化冗余信息。
- 最大池化是取区域内的最大值，平均池化是取区域内的平均值
# 5. 什么是感受野？
- 输出的一个点对应输入图的区域大小。
