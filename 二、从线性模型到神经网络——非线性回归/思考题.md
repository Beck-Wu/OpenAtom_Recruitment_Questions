# 1.模型能力从哪来？
- 相较于线性模型，MLP模型的主要优势是加入了激活函数。  
线性模型本身只能解决线性问题，但不少实际问题是非线性的，即使对线性模型叠加层数，得到的也还是线性模型；  
激活函数使得MLP模型非线性化，叠加层数能使参数增加，拟合强度有效增大。
- 线性模型测试集 R²=0.739，MLP 提升到 0.842；参数量从 11 个增加到 2817 个。
更关键的是训练损失曲线的形态——线性模型损失在几十个 epoch 内就触底、之后 270 多轮卡在 0.267几乎不下降；
而 MLP 的损失持续下降了两个数量级（降到 0.003），说明它在整个训练过程中一直有能力学到新的规律。
# 2.“更深”一定意味着“更强”吗？
- 不一定。这种线性模型的叠加得到的还是线性结构，没有进步。
- y=w1*x1+b1  
y=w2(w1*x1+b1)+b2  
……  
y=wn·(W{n-1}·(...(w1·x + b1)...) + b{n-1}) + bn  
 =wx+b  
所以本质上还是线性结构，拟合能力没有提升。
# 3. 模型越复杂越好吗？
- 不一定，可能会出现过拟合的现象。
- 模型过于复杂，可能过分拟合训练集的细节和噪声，反而偏离了训练集的规律，导致对训练集的拟合程度高，而对测试集的拟合程度低。
