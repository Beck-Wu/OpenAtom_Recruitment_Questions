# 最终测试结果及评价指标

测试集上的结果（已还原到原始 `y` 尺度）：

| 指标 | 数值 |
|---|---|
| MSE  | 5.9659 |
| RMSE | 2.4425 |
| MAE  | 1.8856 |
| R²   | 0.7386 |

## 指标说明

- **MSE**：预测误差平方的平均值，对较大误差施加更重的惩罚。
- **RMSE**：MSE 开根号，单位还原为 `y` 本身的单位，更直观。
- **MAE**：预测误差绝对值的平均值，对异常值不如 MSE/RMSE 敏感。
- **R²**：模型相比"只用均值预测"所解释掉的数据波动比例，取值越接近 1 越好；0.7386 表示模型解释了约 73.9% 的数据变化。
