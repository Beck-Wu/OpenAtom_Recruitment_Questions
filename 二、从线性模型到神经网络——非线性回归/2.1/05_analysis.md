# 实验结果分析

`make_friedman1` 的真实生成函数包含 `10·sin(π·x1·x2)`、`(x3-0.5)²` 等非线性与交互项，本质上是一个非线性回归问题，而线性模型只能给出数据的最佳线性近似。

从结果看，R²≈0.74，说明线性模型已经捕捉到数据中相当一部分的变化趋势——这是因为 Friedman1 函数里也包含若干线性项（如 x4、x5 的系数项），线性模型能较好地处理这部分。但从预测值与真实值的散点图可以看出，预测值的分布明显比真实值"收缩"（真实值跨度更宽，预测值挤在中间），这正是线性模型无法表达 `sin` 交互项和平方项的典型表现：它只能用一个固定方向的线性组合去逼近一个本质上弯曲的函数关系。

训练损失曲线在下降后趋于平台，说明模型已经收敛到其表达能力范围内的最优解，剩余误差主要来自模型结构本身的表达能力不足（对非线性结构的欠拟合），而不是训练不充分。这也为后续任务 2.2 中引入隐藏层、使用全连接神经网络进行对比提供了基线：预期非线性模型能够显著降低这部分由"模型容量不足"带来的误差。
