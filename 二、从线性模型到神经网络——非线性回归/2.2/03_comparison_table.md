# 线性模型 vs 全连接神经网络（MLP）对比表

| 维度 | 线性模型（任务 2.1） | MLP（任务 2.2） |
|---|---|---|
| 网络结构 | `10 → 1`（无隐藏层） | `10 → 64(ReLU) → 32(ReLU) → 1`（2 个隐藏层） |
| 可训练参数量 | 11 | 2,817 |
| 激活函数 | 无 | ReLU |
| 优化器 / 学习率 | Adam / 0.01 | Adam / 0.005 |
| batch size / epoch | 64 / 300 | 64 / 300 |
| 训练结束时标准化训练损失 | 0.2667 | 0.0031 |
| 测试集 MSE | 5.9659 | **3.6107** |
| 测试集 RMSE | 2.4425 | **1.9002** |
| 测试集 MAE | 1.8856 | **1.4831** |
| 测试集 R² | 0.7386 | **0.8418** |

**要点**：
- MLP 的参数量是线性模型的约 **256 倍**，换来测试集 R² 从 0.739 提升到 0.842，RMSE 下降约 22%。
- 线性模型的训练损失在很早就进入平台期（欠拟合，模型容量不足）；MLP 的训练损失持续下降、最终值低两个数量级，说明它有能力拟合数据中的非线性结构。
