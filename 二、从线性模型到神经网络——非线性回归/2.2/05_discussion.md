# 对两个模型差异的理解

## 1. 表达能力（模型容量）的差异

线性模型本质上只能学到输入特征的一个固定线性组合 `y = Wx + b`，它的"假设空间"是所有超平面的集合。而 `make_friedman1` 的真实生成函数包含 `10·sin(π·x1·x2)` 这样的乘积项和三角函数，以及 `(x3-0.5)²` 这样的平方项，这些函数形状是线性模型无论怎么调参都表达不出来的——这不是"没训练好"，而是"模型结构里压根没有这种函数形式"。

MLP 通过隐藏层 + ReLU 非线性激活函数，把输入空间反复做分段线性变换再组合，理论上可以以任意精度逼近连续函数（万能逼近定理）。这就是为什么同样的数据、同样的训练流程，MLP 的 R² 能从 0.739 提升到 0.842。

## 2. 训练过程体现出的差异

从损失曲线能直接"看到"表达能力的差异：线性模型的损失很快（几十个 epoch 内）就触底进入平台期，之后 300 个 epoch 几乎不再下降——这是典型的**欠拟合**信号：不是优化没收敛，而是模型结构限制了能达到的最低损失。MLP 的损失则持续、平滑地下降了两个数量级，说明优化过程中模型一直在学习到新的、更精细的规律，直到训练后期才逐渐趋缓。

## 3. 复杂度与成本的代价

MLP 的参数量（2817）是线性模型（11）的约 256 倍，相应地训练也更"娇贵"一些：需要更小心地选学习率（这里把线性模型的 0.01 降到了 0.005，否则在非凸损失面上容易震荡）、更容易过拟合（如果数据量更小或噪声更大，MLP 的测试误差可能不降反升，而线性模型由于假设空间小，过拟合风险天然更低）。这里数据量（1500 样本）相对参数量还算充足，加上 `noise=1.0` 不算很大，所以没有看到明显的过拟合迹象（训练损失远低于测试误差对应的损失，但测试 R² 依然稳定提升）。

## 4. 一句话总结

线性模型的误差主要来自"模型结构表达不了非线性关系"（高偏差、欠拟合）；MLP 通过引入隐藏层和非线性激活函数扩大了假设空间，用更多参数和更复杂的优化过程换来了更低的偏差，在这个任务和这个数据规模下，这种权衡是值得的。
