# 1. 学习率:什么是学习率（Learning Rate）？学习率设置过大或过小分别可能对模型训练产生什么影响？实际训练过程中可以通过哪些方法调整学习率？
- 神经网络训练中，w和b的更新要减去学习率乘以梯度。所以学习率是参数更新的步长。
- 学习率过小虽然安全不易出错，但时间长，效率低。
- 学习率过长会使损失函数的值不断越过最低点，一直无法降低损失函数。
- 一般先设置一个值，如0.01，再根据运行结果调整
# 2. 损失函数:什么是损失函数（Loss Function）？它在模型训练过程中起什么作用？分类任务和回归任务为什么通常会使用不同的损失函数？
- 是衡量模型预测值和真实值的差距的函数，损失函数值越小，说明预测值与测试值差距越小
- 分类任务预测概率，关心给正确类别的概率有多高，适合交叉熵
- 回归任务预测数值，关心预测值和真实值的差距，适合MSE和MAE
# 3. 过拟合与欠拟合:什么是过拟合（Overfitting）？什么是欠拟合（Underfitting）？它们通常分别有哪些表现？可以通过哪些方法进行改善？
- 过拟合是损失函数很小，但模型对新数据的拟合能力较差
- 欠拟合是损失函数较大，模型对新数据的拟合能力也差
- 过拟合表现是模型将噪声等细节进行学习，或模型过于复杂，忽略了数据的总体规律
- 欠拟合表现是损失函数一直无法下降
- 过拟合改善：精简模型，增加数据，正则化
- 欠拟合改善：增加模型复杂度，加长训练时间，增加特征
# 4. 梯度下降:什么是梯度下降（Gradient Descent）？它为什么能够用于优化神经网络参数？Batch Gradient Descent、SGD 和 Mini-batch Gradient Descent 有什么区别？
- 梯度下降是沿着梯度的反方向调整参数，不断降低损失函数的值，提高模型拟合能力
- 神经网络的参数可导，所以可以求出梯度，而梯度是函数增长最快的地方，则梯度下降是函数下降最快
- Batch Gradient Descent（批量梯度下降）：用全部训练数据算一次梯度，更新一次。
- SGD（随机梯度下降）：每次只用一条样本，更新一次。
- Mini-batch Gradient Descent（小批量梯度下降）：每次用一小批（比如 64 条）样本，更新一次。
# 5. 前向传播与反向传播:什么是前向传播（Forward Propagation）和反向传播（Backpropagation）？神经网络为什么需要反向传播才能完成训练？
- 前向传播是求出预测值结果，反向传播是根据预测值更新参数
- 如果不进行反向传播，参数就得不到更新，模型就没有学习，从而无法提高拟合能力
# 6. 激活函数:为什么神经网络中需要加入非线性激活函数？如果一个多层神经网络中的所有激活函数都被删除，会发生什么？请简单比较 ReLU、Sigmoid 和 Tanh 的特点。
- 不加入非线性激活函数，模型不论添加多少层，函数任然是线性的，因此模型复杂度没有提升
- 神经网络退化成线性函数，只能学习线性关系，泛用性极差
- ReLu计算很快，正区间恒为正，能缓解梯度消失；负区间恒为0，使特征明显，降低干扰
- Sigmoid范围为0到1，使用于概率的预测
- Tanh输出范围为-1到1，输出均值接近0
# 7. 梯度消失与梯度爆炸:什么是梯度消失（Vanishing Gradient）和梯度爆炸（Exploding Gradient）？它们为什么会影响深层神经网络的训练？有哪些常见的缓解方法？
- 梯度消失：反向传播过程中，梯度不断缩小，最后为0，模型参数不再更新
- 梯度爆炸：反向传播中梯度巨幅增大，模型参数变化失控，训练崩溃
- 缓解方法：
- - 对于梯度消失，可以更换激活函数，比如ReLu，以及残差连接
- - 对于梯度爆炸，可以设定梯度阈值，可以降低学习率
# 8. Epoch、Batch Size 与 Iteration:请解释 Epoch、Batch Size 和 Iteration / Step 分别是什么。Batch Size 的大小会对训练速度、显存占用以及模型训练产生哪些影响？
- Epoch：所有训练集被完整使用过一次
- Batch Size：每次训练的样本数
- Iteration：一次参数更新
- Batch Size影响：
- - 训练速度：size太小使总体更新缓慢，size太大使每次训练的数据较多，较慢。
- - 显存占用：size越大，显存占用越大
- - 模型训练：size太小会使梯度噪声大，更新不稳定；size太大会使泛化能力较差
# 9. 优化器:优化器（Optimizer）在神经网络训练中负责什么？请简单比较 SGD 和 Adam 的特点，并说明为什么不同优化器可能得到不同的训练结果。
- 优化器根据梯度调整参数，更新参数
- SGD对所有参数使用同一个学习率，Adam对每个参数有不同学习率
- SGD每次更新只依据当前梯度，而Adam会依据之前所有梯度，故用Adam的模型泛化能力更强
# 10. 训练集、验证集与测试集:训练集（Training Set）、验证集（Validation Set）和测试集（Test Set）分别有什么作用？什么是数据泄漏（Data Leakage），为什么它会导致实验结果失去可信度？
- 训练集用来训练模型；验证集用来调超参数，选最佳模型；测试集用来评估模型拟合能力和泛化能力
- 数据泄露是指模型在训练的时候接触了验证集和测试集，从而导致测试结果失去可靠性
- 因为数据泄露就是模型用了测试集进行训练，那么再用这个测试集来测试，测试结果必然会较高
# 11. 正则化:什么是正则化（Regularization）？它主要用于解决什么问题？请简单说明 L1/L2 Regularization 和 Dropout 的基本思想。
- 正则化是降低模型复杂度的手段，主要解决过拟合问题
- L1正则化是在损失函数基础上加上正则化系数乘以参数w的绝对值的和，使参数的大小影响损失函数，并且有稀疏化能力，可以使某些w变为0，强化特征
- L2正则化是在损失函数基础上加上正则化系数乘以参数w的平方的和，使参数的大小影响损失函数，并且尽可能使每个w的影响都参与进来
- dropout是每次前向传播时随机设置部分神经元输出为0，防止部分w的过分影响
# 12. 数据标准化与归一化:为什么训练神经网络之前经常需要对输入数据进行标准化（Standardization）或归一化（Normalization）？它们之间有什么区别？数据尺度差异过大可能给训练带来什么问题？
- 每种数据的量纲不同，不标准化或归一化，损失曲面细长，梯度下降来回震荡
- 标准化是x减均值再除以标准差；均值为0，标准差为1；不改变分布，受异常值影响较小
- 归一化是x减最小值再除以最大值和最小值的差；数据缩放到0到1；改变分布，且受异常值影响大
- 问题：梯度下降震荡；学习率难调；激活函数饱和；正则化不公平
# 13. Batch Normalization:什么是 Batch Normalization？它通常放在神经网络的什么位置？为什么使用 BatchNorm 的模型在训练阶段和推理阶段需要采用不同的工作方式？
- 对 batch 每个特征维度归一化，再加可学习的 γ、β
- 通常放在卷积层和激活函数之间
- 训练阶段：用当前batch的均值方差
- 推理阶段：用训练积累的全局统计量
- 训练阶段的方法能使训练稳定，防止过拟合；推理阶段的方法能最大程度利用经验
# 14. 分类模型的评价指标:Accuracy、Precision、Recall、F1-score 分别表示什么？在类别极度不平衡的数据集中，为什么只看 Accuracy 可能产生误导？什么情况下应该更加关注 Precision，什么情况下应该更加关注 Recall？
- 准确率表示预测对的占所有样本的比例；精确率表示预测为正的样本里真正为正的；召回率表示真正为正的样本里被预测为正的；F1-score是精确率和召回率的调和评价，能更广泛评价模型正确率
- Accuracy会被多数数据主导，所有如果要关心少数类的，Accuracy没什么参考价值
- 要关注误报率，用Precision
- 要关注漏报率，用Recall
# 15. 参数、超参数与模型泛化:什么是模型参数（Parameter），什么是超参数（Hyperparameter）？请分别举例。什么叫模型的泛化能力（Generalization Ability）？模型参数更多、网络更深是否一定意味着泛化能力更强？为什么？
- 模型参数是模型在学习过程中自动调整的参数，比如w和b
- 超参数是人为调整的参数，比如学习率，batch size，正则化系数，dropout比例，epoch数
- 模型的泛化能力是指模型面对新数据的拟合能力
- 模型参数越多，网络更深可能会出现过拟合现象，泛化能力变差
